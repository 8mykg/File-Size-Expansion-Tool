# File Resizer Pro!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

ブラウザ上で指定したファイルサイズ（MB）にサクッと増減できるWebツールです。
テストデータの作成や、異常系テスト用の破損ファイルの準備に最適です。
高画質化や圧縮用途ではありませんので注意。
また出力ファイルが必ず動作するとは限りません。

## 🌟🌟🌟🌟 特徴 🌟🤡🌟🌟
- **完全ローカル処理**: サーバーにファイルを送信しないため高速＆安心
- **3つのモード**:
  - 自動調整（指定サイズに拡大/縮小）
  - 強制パディング（ゼロ埋め追加）
  - 強制トリミング（指定サイズでカット）
- **インストール不要**: ブラウザだけで動きます

## 🔗 ライブデモ
[ツールを使ってみる]([https://8mykg.github.io/File-Size-Expansion-Tool/])

## 🛠️ 使い方
1. ファイルを選択します。
2. 目標のファイルサイズ（MB）を入力します。
3. モードを選んで「ファイルを変換＆ダウンロード」を押すだけ！
